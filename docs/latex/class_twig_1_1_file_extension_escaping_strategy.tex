\doxysubsection{Description détaillée}
Default autoescaping strategy based on file names.

This strategy sets the HTML as the default autoescaping strategy, but changes it based on the template name.

\doxylink{class_note}{Note} that there is no runtime performance impact as the default autoescaping strategy is set at compilation time.
