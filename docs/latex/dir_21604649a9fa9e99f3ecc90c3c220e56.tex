👋 Hey, I\textquotesingle{}m Amauri, a french dev that build a GDPR friendly cookie manager.

tarteaucitron was initially a simple script for my personal blog (in 2013), a few months later, the Github repository is opened and tarteaucitron is now reliable and recognized.

The european cookie law regulates the management of cookies and you should ask your visitors their consent before exposing them to third party services.

Clearly this script will:\+
\begin{DoxyItemize}
\item Disable all services by default,
\item Display a banner on the first page view and a small one on other pages,
\item Display a panel to allow or deny each services one by one,
\item Store the consent in a cookie for 365 days.
\end{DoxyItemize}

Bonus:\+
\begin{DoxyItemize}
\item Load service when user click on Allow (without reload of the page),
\item Incorporate a fallback system (display a link instead of social button and a static banner instead of advertising).

\item (document) {\ttfamily \{SERVICE\+\_\+\+KEY\}\+\_\+loaded} for each enabled service
\item (document) {\ttfamily \{SERVICE\+\_\+\+KEY\}\+\_\+allowed} for each service when allowed
\item (document) {\ttfamily \{SERVICE\+\_\+\+KEY\}\+\_\+disallowed } for each service when disallowed
\item (window) {\ttfamily tac.\+root\+\_\+available}:\+ the root element with panel has been created, services will be loaded
\item (window) {\ttfamily tac.\+open\+\_\+alert}
\item (window) {\ttfamily tac.\+close\+\_\+alert}
\item (window) {\ttfamily tac.\+open\+\_\+panel}
